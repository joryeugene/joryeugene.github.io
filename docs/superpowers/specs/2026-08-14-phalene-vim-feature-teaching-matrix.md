# Vim Feature and Teacher Curriculum Matrix

## Required learner outcome

A new learner starts with `:teacher`, repairs small files with guided help, transfers each skill to a new task, and completes the six-file analytics incident without an exact command script.

The course keeps `:tutor` as the classic reference. It uses the existing browser editor, document registry, key dispatcher, help system, and teacher controller.

## Lesson acceptance

Each required unit must include these checks:

1. The guide states one real purpose.
2. The worked example shows before text, command, and after text.
3. The guided task names the command family.
4. The transfer task names only the required file result.
5. `:teacher check` reports the first visible unmet result.
6. Three hints move from concept to grammar to exact route.
7. `:teacher golf` remains locked until the file is correct.
8. A later unit or the project reuses the skill.

## Test ownership

| Journey | Test scope | Required result |
|---|---|---|
| Fresh start | Focused course browser test | `:teacher` starts Unit 1. |
| Lesson progression | One focused test per new behavior slice | The learner completes the file and advances. |
| Progressive hints | Course controller test | Hints advance once and never edit the file. |
| Lesson selection | Course controller test | Selection does not mark skipped work complete. |
| Explorer integration | Course navigation test | `:Ex` lists and opens active teacher files. |
| Local progress | Reload test | Completion IDs return. Learner file contents do not. |
| Privacy-safe export | Export test | The JSON contains summaries and no document or key data. |
| Mobile path | Mobile teacher test | A learner starts, edits, checks, and advances one lesson. |
| Classic tutor | Existing tutor suite | `:tutor` behavior remains unchanged. |
| Applied project | Existing full teacher journey | The final postmortem remains exact. |
| Complete course | One serial end-to-end journey | Unit 1 through the capstone finishes in one browser. |

All Playwright work uses one process and one worker. Run each verifier serially.

## Human playthrough gate

Round one uses five fresh starts. Record the exact lesson, starting text, learner action, confusion, hint level, recovery, and final file.

Revise a lesson when more than two learners need the exact route or when two learners make the same incorrect inference.

Round two requires five consecutive journeys without a blocker. At least four learners must finish the final transfer without the exact-route hint.

Do not publish speed, fluency, or retention claims from automated runs.
